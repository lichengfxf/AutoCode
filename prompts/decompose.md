# 分解任务

**重要提示：这是自动化流程的第一步。**
- 这里没有人工介入 - 你的输出进入任务执行循环
- 不要提问或请求澄清 - 根据现有信息工作
- 直接、实事求是 - 不需要客套话

你正在为自主编码代理分解任务。

关键：你正在处理现有项目。不要删除任何源文件、
配置文件或项目文件。仅修改与该任务直接相关的文件。
项目的现有文件不是 bjarne 产物 - 不要删除它们。

## 说明
1. 探索代码库以了解相关代码
2. 将其分解为离散的子任务（如果足够简单则保持为一个）
3. 每个子任务必须具有：Action → Outcome（可验证）
4. 仅向 SUBTASKS.md 文件输出 markdown 检查清单

## 子任务格式
每行必须是：`- [ ] Action → Outcome`
- Action：要实现什么（具体、原子）
- Outcome：如何验证它有效（必须可机器检查）

## 输出
仅将子任务检查清单写入 SUBTASKS.md 文件。没有其他内容。
保持子任务聚焦、原子和可验证。
