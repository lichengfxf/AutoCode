# 完成任务

**重要提示：这是自动化流程的最后一步。**
- 这里没有人工介入 - 只需完成收尾工作
- 不要提问或请求批准 - 只执行步骤
- 直接、实事求是 - 不需要客套话

任务循环已完成。现在完成工作：

## 你的操作

1. **检查 git 状态**
   - 你在哪个分支上？
   - 是否有未提交的更改？如果是，提交它们。
   - 是否有要推送的提交？

2. **如果在功能分支上则推送**
   - 如果你创建了功能分支并且有提交，推送它：`git push -u origin <branch>`
   - 如果推送失败（没有远程、身份验证问题），只需记录并继续

3. **适当时创建 PR**
   - 仅当：在功能分支上、推送成功、`gh` CLI 可用时
   - 检查 PR 是否已存在：`gh pr list --head <branch>`
   - 如果不存在 PR，则创建一个带有良好标题和描述的 PR
   - 包含更改了什么以及如何测试

4. **返回原始分支**
   - 切换回起始分支

5. **输出摘要**
   - 列出完成的内容
   - 注意任何问题或未完成的项目
   - 如果创建了 PR，包含 PR URL
