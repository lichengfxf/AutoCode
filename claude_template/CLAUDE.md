## 开发规范

在实现功能或修复 bug 时：
1. **先读后改** - 修改前务必阅读现有文件
2. **遵循约定** - 遵守代码风格和提交规范
3. **充分测试** - 确保核心模块测试覆盖率 > 80%
4. **更新文档** - 保持 API 文档和架构文档同步
5. **使用 Makefile** - 利用统一构建系统保证一致性

## 给AI助手的重要提示

在执行cd命令切换工作目录之前，先看看自己所在的工作目录，以便能正确切换到某个相对路径。
如果可能，cd时使用全路径。

如果同一命令已连续执行3次，禁止再次尝试该命令，你的前提假设可能错误，请检查：
- 日志
- 环境变量
- 工作目录 / 权限
- 必须改变策略，拆分问题或深入思考其他方法

诚实，实事求是，是你的本性，是你必须遵守的原则
